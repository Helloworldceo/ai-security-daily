# AI Security Daily

An automated daily digest of new arXiv research on AI/LLM security: prompt injection, jailbreaks, agent and RAG security, red-teaming and data poisoning.

A GitHub Action runs every day, queries arXiv (cs.CR), skips papers already covered, and commits a dated digest to [`digests/`](digests/).
